# Spatial Source Integrity v0.4 — Architecture Revision Summary

**Status:** SUPERSEDED / HISTORICAL  
**Superseded by:** `docs/01_SPATIAL_SOURCE_INTEGRITY_V1_BASELINE_TRIPLE_REVIEW.md`

This file preserves the major decisions of the v0.4 architecture revision that preceded the final v1 triple review. It is retained for design history only and is **not** the implementation authority.

## v0.4 shift
The project moved from a “spatial quality detector / trust score” concept to an **evidence-backed, executable, decision-specific admission layer**.

Core v0.4 decisions included:
- shared semantic contracts first;
- `prism-ontology` as semantic upper layer;
- OperationalProfile separated from DecisionProfile;
- raw immutable;
- UNKNOWN/CONFLICT valid;
- CRS identity separated from operational alignment;
- candidate ranking separated from absolute adequacy;
- out-of-set rejection;
- held-out anchors;
- decision stability;
- evidence relation to explicit claims;
- evidence dependence tracking;
- Gold independence grades;
- B0–B5 benchmark;
- DetectorExecution states;
- versioned snapshot lifecycle;
- no formal consumer access without GateDecision.

## Superseded terminology
The final v1 Baseline further normalized:
- `DecisionReadyProjection` instead of `TrustedProjection`;
- `QUARANTINE_SCOPE` as GovernanceDisposition rather than GateAction;
- mandatory shared Claim semantics;
- `EvaluationCoverageManifest`;
- strict sample-vs-record authorization;
- unique Spatial Admission Publisher;
- repair mapped to DerivedEstimate + explicit RepairApproval;
- HITL as a first-class control loop;
- learning infrastructure reuse and RL demotion to optional research.

Use this file only to understand architectural evolution.
